### 🚌 FU-Bus — Online Bus Ticket Booking System

An academic team project for managing bus trips and ticket bookings.

**Technologies:** Java, JSP, Servlets, JSTL, SQL Server, JDBC, Maven.

**Project features:**

- User registration, login, and logout.
- Search for available bus trips.
- Book tickets and view booked tickets.
- Manage buses, routes, and trips through an admin interface.
- Provide separate access controls for administrators and staff.
- Support reporting.

**Project structure:**

- JSP pages for the user interface.
- Servlets for handling requests.
- DAO classes for database access.
- Model classes for application data.
